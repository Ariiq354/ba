# Issue Tracker: GitHub Issues

This repository uses **GitHub Issues** as its primary issue tracker.

## Operations

- **Reading issues / PRs**: Use `gh issue list`, `gh issue view <id>`, `gh pr list`, `gh pr view <id>` via the GitHub CLI (`gh`).
- **Creating issues**: Use `gh issue create --title "<title>" --body "<body>"`.
- **Updating issues**: Use `gh issue edit <id>` or comment via `gh issue comment <id> --body "<body>"`.
- **Closing issues**: Use `gh issue close <id>`.

## Pull Requests as Request Surface

- **PRs as a request surface**: `false`
