# Triage Label Vocabulary

This repository uses the canonical triage label set for agent/human issue workflows.

## Canonical Roles and Labels

| Role              | Label Name        | Purpose                                              |
| ----------------- | ----------------- | ---------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Newly created issues awaiting initial classification |
| `needs-info`      | `needs-info`      | Waiting for additional input from submitter/user     |
| `ready-for-agent` | `ready-for-agent` | Triaged and ready for an AI agent to execute         |
| `ready-for-human` | `ready-for-human` | Requires human review or manual intervention         |
| `wontfix`         | `wontfix`         | Out of scope or closed without action                |
